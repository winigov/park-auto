# Парк Авто — сайт

Продающие лендинги моделей для «Парк Авто» (Махачкала): SEO и Директ в Яндексе, трафик из соцсетей, сбор заявок на тест-драйв.

Стек: [Astro](https://astro.build) (статический сайт), GSAP (анимации при прокрутке), шрифт Manrope (хранится на сервере сайта).

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # готовый сайт в dist/
```

Нужен Node.js 22+. Для перехода на Astro 7 обновите Node до 22.12 или новее.

## Где что менять

| Что | Файл |
|---|---|
| Телефон, адрес, мессенджеры, условия кредита | `src/config/site.ts` |
| Фирменные цвета | `src/styles/global.css`, переменные `--accent*` |
| Логотип | `src/components/Logo.astro` |
| Данные модели: цены, характеристики, тексты, FAQ | `src/data/models/geely-m7.ts` |
| Тексты про учёт РФ и КР | `src/data/registration.ts` |
| Преимущества компании | `src/data/company.ts` |
| Фото модели | `src/assets/<модель>/`, импорт в файле модели |

## Как добавить модель

1. Положить фото в `src/assets/<slug>/`.
2. Скопировать `src/data/models/geely-m7.ts` в `src/data/models/<slug>.ts` и заполнить.
3. Добавить модель одной строкой в `src/data/models/index.ts`.

После этого модель сама появится:
- на отдельной странице `/<slug>/`;
- в каталоге на главной, с фильтрами по кузову, числу мест и двигателю;
- в меню «Модели» в шапке;
- в калькуляторе кредита и в формах заявок;
- в блоке «Другие модели» на страницах остальных машин.

**Обязательные поля:** название и бренд, тип кузова, тип двигателя, число мест, наличие, фото для первого экрана, 3 цифры для карточки, комплектации с ценами РФ/КР, характеристики, SEO.

**Необязательные поля** — «история» (`chapters`), салон (`interior`), технологии (`tech`) и галерея (`gallery`). Если их нет, эти блоки на странице просто не выводятся. Модель можно быстро добавить в каталог, а промо-блоки дописать потом.

**Настройки показа:**
- `featured: true` — модель попадает на первый экран главной;
- `order` — порядок в каталоге, чем меньше, тем выше;
- `isNew` — бейдж «Новинка».

## Демо-версия на GitHub Pages

```bash
npm run deploy:demo
```

Собирает сайт с плашкой «Прототип» и запретом индексации и публикует его в ветку `gh-pages`. Адрес: https://winigov.github.io/park-auto/

## Заявки

Формы отправляют JSON на `PUBLIC_LEAD_ENDPOINT` (см. `.env.example`). Пока адрес не задан, формы работают в демо-режиме: заявка выводится в консоль браузера.

Что уходит в заявке: имя, телефон, модель, комплектация, тип заявки (тест-драйв, цена, кредит, учёт), страница, UTM-метки, `yclid` и реферер.

Если задан `PUBLIC_YM_ID`, подключается Яндекс Метрика с целями `lead_open` и `lead_submit`.
